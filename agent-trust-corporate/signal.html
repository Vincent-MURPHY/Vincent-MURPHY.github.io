AGENT TRUST SIGNAL · PROPOSED PRODUCT

Security intelligence for connected AI.

An independent, developer-first approach to AI dependency visibility, authenticated security notifications and contractual assurance evidence.

Three capabilities under development

Dependency inventory

Authorised MCP and A2A metadata, gateway logs and customer-supplied inventories. No claim of complete discovery.

Security signals

Source-attributed advisories, affected versions, timestamps, confidence, corrections and revocation. Customer policy controls response.

Security Annex evidence

Customer-defined requirements for authentication, encryption, logging, incident notification and other controls. Evidence gaps are not automatic compliance failures; human review is required.

Proposed open API

POST /v1/dependencies/resolve
GET /v1/signals
POST /v1/assessments

Illustrative interface design only. No public backend, production feeds, certification or regulatory approval is currently claimed.

Open ecosystem

Planned open schemas and SDKs, with interoperability targets including MCP, A2A and existing security tooling. No partnerships or endorsements claimed.
